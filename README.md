Spinning Heart Animation

A Python graphics script that creates a 3D spinning heart made of text, along with a falling particle background and a central animated GIF.

Requirements

Python 3.x

turtle (built into Python)

Pillow (Python Imaging Library)

You can install the required library using pip:

pip install Pillow


How to Run

Ensure you have a GIF named cat.gif in the same folder as the script.

Run the Python file from your terminal or command prompt:

python heart_name.py
